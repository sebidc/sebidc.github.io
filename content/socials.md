# Social platforms & links

Add your public profile URL in the URL column and save. The live Socials page reads this file automatically. Optionally run `python3 scripts/build.py` to update its no-JavaScript fallback.
Every platform appears on the Socials page. Filled HTTPS URLs become clickable profiles; `PLACEHOLDER` entries show “Link coming soon”. Remove a row to hide a platform, or add a row for another service.
For email, replace the placeholder with `mailto:you@example.com`.
Do not enter passwords, API keys, or private contact details here: this repository is public.
